# AI Email Assistant

AI Email Assistant is a simple web application that uses Generative AI to create professional emails.

## What This Project Does

The user selects an email type and describes what they want to write.

The AI then creates a professional email automatically.

For example, the user can generate:

- Job Application emails
- Interview Follow-up emails
- Leave Request emails
- College Request emails
- Complaint emails
- General emails

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Google Gemini AI
